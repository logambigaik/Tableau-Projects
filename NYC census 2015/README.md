# 📊 NYC Tree Census 2015 - Tableau Visualization

This project visualizes the **NYC Tree Census 2015** dataset using Tableau. The goal is to explore the city's urban forestry across boroughs, species, health conditions, and more — presented through an interactive dashboard.

🔗 **Live Dashboard:**  
👉 [View it on Tableau public](https://public.tableau.com/views/NYC_tree_census_data_2015/Dashboard1?:language=en-GB&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link)

---

## 🌿 Project Highlights

- **Dataset:** NYC Open Data – Tree Census 2015  
- **Tool Used:** [Tableau Public](https://public.tableau.com/)
- **Topics Covered:**
  - Tree counts by species and borough
  - Health and status of trees
  - Tree distribution visualizations
  - Filters by neighborhood and condition

## 🧩 Dashboard Panel Breakdown

### 1. **Total Tree Count by Borough**
- **Purpose:** Displays the total number of trees in each borough.
- **Insights:** Highlights which boroughs have the most extensive urban tree cover.
- **Visualization:** Bar chart.

### 2. **Tree Health Condition**
- **Purpose:** Shows the proportion of trees in **Good**, **Fair**, or **Poor** condition.
- **Insights:** Understand the health distribution of the tree population.
- **Visualization:** Stacked bar or pie chart.

### 3. **Most Common Tree Species**
- **Purpose:** Lists the most frequently planted tree species in NYC.
- **Insights:** Reveals species diversity and popularity in urban forestry.
- **Visualization:** Horizontal bar chart or ranked list.

### 4. **Tree Steward Activity**
- **Purpose:** Displays how many trees are maintained by stewards (citizens, organizations, or city services).
- **Insights:** Tracks civic engagement in maintaining trees.
- **Visualization:** Bar or pie chart by stewardship level.

### 5. **Map of Tree Locations**
- **Purpose:** Interactive map of trees across NYC.
- **Insights:** Visualizes spatial tree distribution; filterable by species, health, etc.
- **Visualization:** Geographic map.

### 6. **Filters Panel**
- **Purpose:** Lets users filter the data by:
  - Borough
  - Species
  - Health
  - Steward level
- **Insights:** Allows focused, interactive exploration.
