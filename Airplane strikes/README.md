# ✈️ Airplane Wildlife Strikes Dashboard

## 📊 Overview
This Tableau dashboard provides a comprehensive visual analysis of wildlife strikes involving airplanes across major U.S. airports. The dataset includes information on the frequency, financial impact, and trends of wildlife collisions over time.

## 🔍 Dashboard Features

- **By Airport: How Much?**  
  Two treemaps showing the **total cost of wildlife strikes** by airport. Airports like **LaGuardia (LGA)** and **Denver (DEN)** incur the highest costs.

- **By Airport: How Many?**  
  A treemap representing the **number of strikes** per airport. This highlights which airports report the most frequent wildlife incidents.

- **Collisions Over Time (Top 10 Airports)**  
  A line chart showing the **trend of wildlife strikes** over time (2000–2014) for the top 10 affected airports.

- **Airport Code & Rank**  
  Highlights airports by **code and rank**, based on either cost or frequency, helping identify high-risk locations.

## 🎨 Design Highlights

- **Background:** Custom-designed sky/clouds theme with soft tones and rounded/circular layouts to reflect aviation and nature.
- **Layout:** Clear sectioning of data by type (Cost, Frequency, Timeline, Rank).
- **Interactive:** Fully interactive dashboard allowing users to explore details via hover and click.

## 📈 Data Source
This visualization is based on FAA wildlife strike reports and includes:
- Airport codes and names
- Collision dates
- Total financial cost of strikes
- Aircraft details and passenger volumes

## 🚀 Use Case
This dashboard can assist:
- Aviation safety teams
- Airport management
- Environmental monitoring agencies
- Data analysts and Tableau learners
